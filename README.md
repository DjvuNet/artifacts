# DjvuNet Artifacts
This directory contains test images, documents, and binary data used by the [DjvuNet](https://github.com/DjvuNet/DjvuNet) test suites and benchmarks.

-## Contents
-* **`.djvu` files**: Test documents used for parsing, rendering, and structural testing.
-* **`.png` files**: Reference images (backgrounds, foregrounds, masks) generated by the reference `DjVuLibre` implementation, used for pixel-perfect validation of DjvuNet outputs.
-* **`.json` files**: Serialized reference data dumps containing expected document tree structures and metadata.
-* **`ErrorFiles.json`**: Tracking file for known parsing errors or unsupported document formats.
-* **`Raw Binary Artifacts.bin`)**: Some tests and benchmarks require raw memory dumps instead of standard image files to avoid automatic color-space conversions while loading by OS.This is because loading a standard format (like JPEG or TIFF) through .NET's `System.Drawing` (GDI+) forces automatic color-space conversions (e.g., converting YCbCr to BGR in memory).

To test exact algorithms (like `YCbCr2RgbUnified`) with deterministic, pre-calculated YCbCr data without taking a dependency on a 3rd party TIFF library, we use raw `.bin` dumps.

### Naming Convention

Because `.bin` files lack headers, their geometry is encoded in the filename:
`<Name>-<Width>x<Height>-<Format>.bin`

Example: `TitanIR-5447x3686-24bpp-YCbCr.bin`

If you need to regenerate these files, use the generator scripts located in `eng/scripts/`.

-## Releases
-GitHub Releases on this repository are used by the DjvuNet CI/CD pipelines to download immutable snapshots of this test data, alongside compiled assets (`Tools.{zip|tar.gz}`, `deps.{zip|tar.gz}`) required to bootstrap the build environment.
